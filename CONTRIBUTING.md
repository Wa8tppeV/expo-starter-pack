# Contributing

Work on feature branches. Do not commit directly to main.

For DMH Proje Ofisi use:
- dmh-proje-ofisi-v1

Before committing:
1. bun run lint
2. bun run format:check
3. bun run test -- --runInBand

Keep commits small and task-focused. Do not add dependencies unless the existing stack cannot solve the problem cleanly.
